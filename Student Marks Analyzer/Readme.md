# Student Marks Analyzer 📚

## Overview

Student Marks Analyzer is a Python-based console application that helps manage and analyze student marks. 

The project allows users to add student records, view student data, search students, and perform basic analysis like finding maximum marks, minimum marks, total marks, and average marks.

This project is built to practice fundamental programming concepts such as lists, loops, conditional statements, searching, and data manipulation.

---

## Features

- Add student records
- View all student records
- Search student by name or ID
- Find highest marks
- Find lowest marks
- Calculate total marks
- Calculate average marks
- Update student information
- Delete student records
