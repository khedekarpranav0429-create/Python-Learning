Student Management System (Python)
📌 Project Overview

Student Management System is a Python-based application that allows users to manage student records using a dictionary-based data structure.

The project demonstrates the practical use of Python fundamentals such as dictionaries, nested dictionaries, loops, conditional statements, functions, and user input handling.

🚀 Features
Add new student records
Display all student details
Search student by ID
Search student by name
Update student information
Delete student records
Count total number of students
Menu-driven program interface
🛠️ Technologies Used
Python 3.x
